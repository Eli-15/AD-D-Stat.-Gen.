# AD&D Stat. Gen.
## Description
adnd-stat-gen.py is a python script used for generating AD&D 1e character ability scores as laid out on page 11 of the DMG.

## Dependencies 
Python3 

## Usage
adnd-stat-gen.py [ METHOD ]
The command "adnd-stat-gen.py" can be run with either 0 or 1 arguments.  
It uses the argument to skip the dialogue and just run the selected method.  
Running it with either an incorrect argument option or any number of arguments besides 1 will cause it to default to the dialogue mode.
When in dialogue mode the program can be quit at any time by typing and entering 'q'.

### Examples
	adnd-stat-gen.py  
	adnd-stat-gen.py 1  
	adnd-stat-gen.py 3
